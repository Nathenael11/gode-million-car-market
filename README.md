## ?? Getting Started

### 1. Start Server
```bash
cd server
npm install
npm start
```
Server runs at `http://localhost:5000` (`/api/health` for healthcheck).

### 2. Start Client
```bash
cd client
npm install
npm run dev
```
Client runs at `http://localhost:5173`.
